## macOS 安装说明

macOS 的 Apple Silicon（arm64）和 Intel（x86_64）官方安装包均使用 **Apple Developer ID 签名**并通过 **Apple 公证**，应用和 DMG 均附带公证票据。打开 DMG 后将 Aictionary 拖入 Applications，即可正常启动，无需执行终端去隔离命令。

## 新增

- **`aictionary://` 链接查词**：`aictionary://lookup?word=<单词>` 可以从任意 App、快捷指令、脚本或浏览器链接直接打开该词的释义，iOS、Android、macOS、Windows 和 Linux 均支持；应用未运行时会先启动再查询。任何网页都能发起这样的链接，所以链接只查离线词典：词典里没有的词不会自动调用 AI，而是显示「用 AI 生成」按钮，由你确认后才发送请求。无法识别的链接、未指明单词或超过 100 个字符的查询只会提示，不会执行。#41
- **词条页重排**：#39
  - **释义优先**：单词、音标和发音之后直接是释义，记忆提示、学习笔记和词源移到释义之后。同一词性不再按词源拆成多段，而是合并为一节并连续编号；各词性按核心义项、常用义项的数量排序，专有名词排在最后。
  - **速览**：标题下方每个词性一行，列出核心和常用释义，点击即可跳到对应小节。
  - **目录**：词条旁固定显示目录，并标出正在阅读的小节；手机上收窄为单字索引（形、名、动……）。
  - **排版与区分**：统一小节标题、释义、正文和次要信息的字号层级；例句与译文上下紧邻并与释义区分开，例句中的查询词及其变形加粗，义项标签改为标签样式。
  - AI 生成过程中的预览沿用同样的顺序和排版，生成完成后页面不会重新排列。
  - 词库数据目前没有搭配字段，因此暂不标注常见搭配。

## 修复

- **macOS 菜单栏图标**：改用与 Dock 图标一致的应用标志剪影，替换原先辨识度不高的书本图标；按 Retina 分辨率绘制，不再模糊，并继续随系统深浅色自动适配。Windows 和 Linux 仍使用彩色应用图标。#40

## 更新

桌面用户可通过应用内更新升级，也可下载下方安装包；Android 用户下载安装 APK。iOS 版本通过 [TestFlight](https://testflight.apple.com/join/qEzjS8bY) 分发，3.6.0 构建需通过 Apple 审核后才会出现在 TestFlight 中。
