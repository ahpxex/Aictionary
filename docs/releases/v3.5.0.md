## macOS 安装说明

macOS 的 Apple Silicon（arm64）和 Intel（x86_64）官方安装包均使用 **Apple Developer ID 签名**并通过 **Apple 公证**，应用和 DMG 均附带公证票据。打开 DMG 后将 Aictionary 拖入 Applications，即可正常启动，无需执行终端去隔离命令。

## 新增

- **查词小窗**：左键点击托盘 / 菜单栏图标，或按全局快捷键 `⌘/Ctrl ⇧ Space`，呼出浮在当前应用上方的查词小窗。小窗支持输入联想、反查、发音和保存到 Anki，未输入时列出最近查过的词；查完按 Esc 或点击别处即收起，「打开完整词条」会把结果交给主窗口显示。快捷键可在「设置 → 键盘」中修改。Linux 不提供托盘点击事件，只能用快捷键呼出。#38（基于 @Aiden-ProMax 的 #35，感谢）
- **托盘菜单调整**：右键菜单改为「主窗口 / 设置 / 退出」，左键改为开关查词小窗。
- **iOS 适配**：适配刘海和底部安全区域，词库路径在每次启动时重新解析，应用更新后无需重新下载词库。iOS 版本通过 TestFlight 分发：[加入 Aictionary TestFlight 测试](https://testflight.apple.com/join/qEzjS8bY)。

## 修复

- **受限网络下的词库下载**：原生请求补上 GitHub 要求的 User-Agent；GitHub API 限流（403 / 429）时改用 Release 的固定下载地址，词库下载和校验不再依赖 API 配额。
- **移动端搜索**：软键盘显示「搜索」键，查询后自动收起键盘；输入框字号不再触发 iOS 自动缩放。

## 更新

桌面用户可通过应用内更新升级，也可下载下方安装包；Android 用户下载安装 APK。
