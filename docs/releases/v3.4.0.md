## macOS 安装说明

macOS 的 Apple Silicon（arm64）和 Intel（x86_64）官方安装包均使用 **Apple Developer ID 签名**并通过 **Apple 公证**，应用和 DMG 均附带公证票据。打开 DMG 后将 Aictionary 拖入 Applications，即可正常启动，无需执行终端去隔离命令。

## 新增

- **输入联想**：输入字母即可查看本地词库建议，支持上下键、回车、鼠标选择和中文输入法。#17
- **英文词频**：新增独立的 wordfreq 英文词频数据库，覆盖约 30 万个词，展示 Zipf 分数和每百万词出现次数，并附来源与许可。词频与词典数据、个人查询次数分开保存，未收录的词和短语不显示分数。#13
- **自定义 CA**：「设置 → 网络」支持保存 PEM CA 证书，供 AI 流式请求、词典下载、Anki 和语音使用，保留证书及主机名校验。应用自动更新继续使用系统证书库。#32

## 修复

- **macOS 窗口恢复**：关闭窗口后再次点击 Dock 图标可恢复窗口；菜单栏图标改为随系统深浅色自动适配的模板图标。#33
- **Anki 连接**：请求改由原生后端发送，避免 WebView 跨域限制，并确保 Anki 连接不经过外部代理。仍需安装 AnkiConnect 并保持桌面版 Anki 开启。#24
- **Edge 发音连接**：补齐 Windows 系统代理读取，统一 Edge 协议请求头，对临时断连进行有限重试，防止缓存未完成的音频。网络仍不可达时，可在「设置 → 网络」配置代理。#36

## 更新

桌面用户可通过应用内更新升级，也可下载下方安装包；Android 用户下载安装 APK。
